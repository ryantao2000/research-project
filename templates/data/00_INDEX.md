# data · 项目数据

原始数据和跨计划复用的派生数据。只服务一个计划的中间文件放`work/NN_slug/`。

## 维护规则

- `raw/`：原始数据，只读，不进git；登记来源、取得日期、许可与校验和。
- `derived/`：跨计划复用的派生数据，注明生成脚本（`code/`或`work/NN_slug/scripts/`）与输入版本；体积大时不进git。
- 数据划分（训练/验证/测试）一经冻结，在此登记并注明哪些部分已被查看过。
- 备份方式见[OPS](../OPS.md)。
