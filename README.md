# research-project 1.3.1

个人研究工作区的组织方法与模板。入口：[SKILL.md](SKILL.md)。

Goal统领研究，Plan保留Phase表；每个完成的Plan在concepts默认专栏中有可读分析，长期主题再综合跨计划理解。阅读与资料入口维护INDEX，执行事实留work，对外交付留sync；不默认生成防御性中间文件。

新项目默认建立基础目录、各总索引、逐计划分析入口及inbox记录；具体研究内容和运行环境按需创建。sync整个目录（包括索引）不进主仓Git，初始化仍生成本地交付入口，独立管理与备份。根AGENTS自足，日常无需重读skill。初始化时将SKILL.md与templates携带到项目`.agents/skills/research-project/`，仅创建新文档时查模板。部署时也携带，不依赖本机安装路径。

版本记录见[CHANGELOG](CHANGELOG.md)。升级本skill不会自动迁移已采用旧版的项目。
