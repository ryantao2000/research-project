# INDEX的管理方法

INDEX既是导航，也是本目录实际维护入口。实例化时应说明职责、当前有效入口、新增/修改/迁移方法、状态归属以及收尾方式；不要求五个固定标题，无实际需要的部分删除。

通用skill模板保存可复用方法，项目INDEX保存实例化后的规则和内容；项目日常维护不必每次回上游重读。AGENTS只保留常驻边界及按任务路由。下面模板是可选素材，不是目录必须一次建齐的要求。

| 目录 | 实例化模板 | 更新触发 |
|---|---|---|
| 00_knowledge | [总入口](../templates/knowledge-index.md) | 当前重点、重要交付或真正待决定事项变化 |
| 02_subplans | [计划入口](../templates/subplans-index.md) | 新计划或管理规则变化；Phase状态使用项目明确的唯一记录位置 |
| 03_results | [结果入口](../templates/results-index.md) | 实质结果形成或重要判断变化 |
| 05_concepts | [总入口](../templates/concepts-index.md)、[专题入口](../templates/concept-topic-index.md) | 专题关系、学习内容或用户反馈变化 |
| 01_literature | [文献入口](../templates/literature-index.md) | 新材料、版本或提取问题 |
| 02_data | [数据入口](../templates/data-index.md) | 数据、授权边界、划分或处理方法变化 |
| 03_experiments | [实验入口](../templates/experiments-index.md) | 新实验或执行方法变化 |
| 04_upstream | [上游入口](../templates/upstream-index.md) | 来源、版本、用途或适配位置变化 |
| 05_runs | [运行入口](../templates/runs-index.md) | 运行规则或产物定位方式变化，不逐次复制账本 |
| 07_reports | [报告入口](../templates/reports-index.md) | 新报告、版本、证据截止或实际交付变化 |
| 06_sync | [同步入口](../templates/sync-index.md) | 选版、整理或实际远程同步变化 |

补充目录按需管理：问答只记录实际讨论，归纳后的解释进Concepts；事实卡记录核验时间、来源和范围，更新追加更正；Goals安排近期优先级，不重复技术授权；会议用source/extracted分离原件与解读；审稿目录逐项对应意见、动作、证据和回复。可在该目录INDEX直接说明分卷、条目身份和维护方式，不必为每种工作预建完整模板。

迁移前找调用和引用，保留历史原件及映射；移动不改变证据或阅读身份。旧入口可以保留短跳转，但只有一个现行规则入口。发现重复状态时保留权威位置，其他入口改成摘要和链接。维护检查与本次影响匹配，链接通过不表示内容审核通过。
