# Concepts：理解与接续

总INDEX组织专题和共通规则；专题使用语义键，章序是阅读次序，不是研究身份。专题入口说明学习问题、必要前置与逐篇阅读目录。

逐篇目录使用真实Markdown任务列表，每行以 `- [ ] ` 开头；确认读懂时改为 `- [x] `。任务列表写在正文，不能包在代码块、行内代码或表格中；未勾选不等于没读过。
- 初始未确认的文档不勾选；保留“已读”“较大问题”“读到第4节”等旧记录或卡点。助手仅依据用户明确反馈修改勾选。
- 新session先读总入口和专题入口，从实际停点接续；讲解完成、答案给出或检查通过不自动勾选。
- 旧“已读”不能转成勾选；明确“读懂”才可转。实质改写记录范围和建议回看位置，不自动重置旧阅读事实，也不假定新增内容已读。

解释从具体问题、可理解的例子连接到定义和计算。计算模型说明数据、可见输入、隐藏目标及输出，适用时区分训练更新与固定权重推理。受众基础按实际反馈确定，不默认所有专题都要求神经网络知识。

教学构造明确标注；方法事实核对论文或源码；实验判断引用Results。通用解释尽量自足，项目实例保留源码与产物出处。文献原件和提取保存在literature，理解、推导和跨论文比较直接进入Concepts，不强制单篇digest或一文一教程。

先补现有章节，独立学习问题才新建专题。长推导和历史审计按需放reference，主教程与参考材料各自记录读懂状态。共享概念选一处完整解释，其他地方回顾并链接。移动文档检查旧链接和assets，不生长两份活跃正文。

个人默认：行内公式用 `(公式)`，独立公式用独占行的 `$$`，不放普通代码块。历史原文不批量改写。
